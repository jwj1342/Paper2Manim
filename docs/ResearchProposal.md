# Research Proposal

**基于大语言模型多智能体的学术论文到高质量动画视频自动生成系统**

## 1. 研究背景 (Background)

科学研究的产出正呈指数级增长，但学术论文高度密集的文本和复杂的数学公式构成了巨大的知识传播壁垒。视频（尤其是基于可视化的动画）已被证明是降低认知负荷、普及复杂概念的最有效媒介。然而，高质量的学术动画制作（如使用 Manim 库）具有极高的门槛：创作者既需要深刻理解论文的硬核学术内容，又需要具备优秀的剧本重构能力，最后还需要掌握复杂的程序化动画代码（Python/Manim）编写。 近年来，大语言模型（LLM）在长文本理解、逻辑推理和代码生成方面取得了突破性进展。这为自动化跨模态知识转化提供了可能。本项目旨在填补“硬核学术文本”与“程序化视觉代码”之间的系统性空白，探索如何利用 LLM 智能体取代传统的高成本人工创作流。

## 2. 一句话问题 (Core Problem Statement)

**如何构建一个具备自我纠错能力的自主 LLM 多智能体系统，以将冗长、复杂的多模态学术论文自动转化为逻辑连贯、视觉准确且代码可执行的 Manim 动画视频？**

## 3. 三个核心贡献点 (Key Contributions)

- **贡献一：提出首个“论文理解-剧本创作-代码生成”的多智能体协同架构 (Multi-Agent Workflow)** 针对传统单模型生成长代码易产生逻辑断裂的问题，本项目提出一种解耦的智能体工作流。系统包含：**论文解析解析器 (Parser)** 提取核心贡献和公式；**分镜编剧 (Storyboarder)** 将学术逻辑转化为适合视觉呈现的分镜脚本；**Manim 工程师 (Coder)** 负责将自然语言分镜精准映射为复杂的 Python 动画代码。
- **贡献二：设计基于“沙盒执行与视觉反思”的闭环纠错机制 (Execution-based Feedback Loop)** Manim 代码生成不仅面临语法错误，还面临严重的“视觉逻辑错误”（如物体遮挡、坐标越界、公式渲染失败）。本项目引入一个**编译反馈智能体 (Reviewer)**，在沙盒环境中实际运行生成的代码，捕获 traceback 报错以及视觉输出的日志，并将这些反馈回传给 Coder 进行多轮迭代修复，极大提升代码的一次性成功率（Pass@1）。
- **贡献三：构建跨学科的 Paper-to-Video 评估基准与数据集 (Evaluation Benchmark)** 定义一套评估 LLM 生成教育类代码动画质量的全新指标体系，涵盖内容保真度（Faithfulness to Paper）、视觉连贯性（Visual Coherence）和代码可执行性（Executability），并开源一个包含多学科（CS、数学、物理）“论文-分镜-高质量Manim代码”对齐的微调与测试数据集。

------

## 4. MVP (Minimum Viable Product) 版本演进路线图

为了敏捷开发并逐步验证研究假设，项目将分为三个 MVP 阶段推进：

### MVP 1.0：核心链路打通 (Proof of Concept)

**目标：验证从“短文本”到“可执行动画”的最短路径。**

- **输入：** 论文的摘要 (Abstract) 或单一核心定理的纯文本说明。
- **处理逻辑：**
  - 单/双智能体架构：一个 Prompt 负责总结并输出分镜，另一个 Prompt 负责写 Manim 代码。
  - 不包含复杂的纠错，仅依赖底层 LLM（如 GPT-4o / Claude 3.5 Sonnet）的 Zero-shot 代码能力。
- **输出：** 一段 15-30 秒的简单 Manim 视频（包含文字淡入淡出、简单图形绘制、基础公式展示）。
- **验收标准：** 代码能成功跑通并渲染出视频，不报语法错误。

### MVP 2.0：全篇解析与多智能体闭环 (The Core Research Version)

**目标：引入多智能体框架与反思机制，处理完整论文。**

- **输入：** 完整的论文 PDF 文件。
- **处理逻辑：**
  - 引入 PDF 解析模块（如 Nougat 或 Marker），提取结构化文本。
  - **实现完整的 Agent 工作流**：Summarizer -> Storyboarder -> Manim Coder。
  - **核心攻坚 - 引入闭环反馈**：系统能够自动运行 `manim render` 命令，捕获报错信息，LLM 能够根据报错信息自主修改代码，直到成功渲染。
- **输出：** 一段 1-2 分钟的论文概念讲解视频，包含逻辑过渡和动画编排。
- **验收标准：** 系统能在无需人工干预的情况下，通过自我纠错将完整论文转化为流畅播放的结构化动画。

### MVP 3.0：多模态融合与表现力飞跃 (The Production-Ready System)

**目标：提升视觉美感，引入多模态资产，达到接近人类创作者的水平。**

- **输入：** 论文 PDF（含图表） + 用户自定义风格提示词。
- **处理逻辑：**
  - **图表提取与复现**：Vision-LLM 能够看懂论文中的原图/架构图，并在 Manim 中用代码重构它，或者将其作为图片素材（`ImageMobject`）无缝嵌入动画。
  - **复杂排版引擎**：优化 Manim 中的相机移动、场景切换（如 `Wait`, `Transform`, `FadeOut`）的节奏控制。
  - **音画同步 (TTS Integration)**：接入如 ElevenLabs 等高质量 TTS 引擎，生成解说音频，并通过时间戳控制让 Manim 动画的播放与语音解说精确对齐。
- **输出：** 一段 3-5 分钟、带有专业配音、图文并茂、具有极高教育价值的完整 Paper 宣发视频。
- **验收标准：** 生成的视频可以直接上传 YouTube/Bilibili，普通观众能够通过视频清晰理解论文的核心贡献，且具有较好的观赏性。
